Privacy Policy — Tool Doi Soat

Last updated: 18 November 2026

What the app accesses

When a channel owner or manager signs in with Google, Tool Doi Soat requests read-only access to that YouTube channel through the YouTube Data API (youtube.readonly) and the YouTube Analytics API (yt-analytics.readonly). It reads the channel's video list and aggregated statistics such as views, watch time, average view duration and audience demographics.

How the data is used

The data is used only to display internal reports for the team that manages the channel. The app never uploads, edits or deletes videos or any other content.

Storage and sharing

  • Access tokens and statistics are stored only on the team's own computer.
  • Data is not sold, shared with or transferred to third parties.
  • Data is not used for advertising.

Revoking access

You can remove the app's access at any time at myaccount.google.com/permissions. Once access is removed, the app can no longer read the channel's data.

Google API Services User Data Policy

Tool Doi Soat's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
